# H5跳一跳 多人在线版 (H5 Jump Jump Multiplayer)

这是一个基于 HTML5、Three.js 和 Node.js 开发的 3D "跳一跳" 多人在线小游戏。玩家控制哪吒卡通形象，通过蓄力跳跃，挑战更高的分数，并与在线玩家实时比拼。

## 🎮 游戏玩法

1. **蓄力跳跃**：长按屏幕（或按住空格键/鼠标左键）进行蓄力，蓄力时间越长跳得越远。
2. **松开起跳**：松开按键，角色会根据蓄力大小跳向下一个平台。
3. **得分规则**：
   - 成功跳到下一个平台得 1 分。
   - **连击奖励**：如果跳到平台中心，会触发连击，分数指数级增长。
   - **掉落失败**：如果跳出平台范围掉落，则分数重置。
4. **多人互动**：
   - 你可以看到其他在线玩家的实时动作（半透明影子）。
   - 右上角实时更新在线分数排行榜。

## ✨ 特性

- **多人同屏**：基于 WebSocket (Socket.io) 实现的多人位置和状态同步。
- **实时排行**：所有玩家分数实时更新，竞争排行榜榜首。
- **角色形象**：可爱的哪吒 3D 形象，带有飘带和风火轮动画。
- **3D 视觉体验**：使用 Three.js 渲染，包含阴影、光照和正交视角。
- **物理反馈**：蓄力压缩、空中翻滚、平滑转向。
- **连击系统**：中心落点检测，完美跳跃奖励。
- **音效系统**：蓄力、跳跃、落地、得分音效反馈。
- **多端适配**：完美适配 PC 和移动端。

## 🕹️ 操作指南

| 平台 | 操作方式 |
| --- | --- |
| **PC (键盘)** | 按住 `空格键` 蓄力，松开跳跃 |
| **PC (鼠标)** | 按住 `鼠标左键` 蓄力，松开跳跃 |
| **移动端** | 按住 `屏幕` 蓄力，松开跳跃 |

## 🛠️ 技术栈

- **前端**: HTML5, CSS3, Three.js, Socket.io-client
- **后端**: Node.js, Express, Socket.io

## 🚀 如何运行

1. 克隆本项目到本地：
   ```bash
   git clone https://github.com/xdmrll1314/oneDayOneProject.git
   ```

2. 进入项目目录：
   ```bash
   cd 2026011201
   ```

3. 安装依赖：
   ```bash
   npm install
   ```

4. 启动服务器：
   ```bash
   node server.js
   ```

5. 在浏览器中访问：
   打开 `http://localhost:3000` 即可开始游戏。
   可以打开多个浏览器窗口模拟多玩家场景。

## 📂 文件结构

- `server.js`: Node.js 服务器入口，处理 WebSocket 连接和游戏状态。
- `game.js`: 核心游戏逻辑，包含 3D 渲染、物理引擎和 Socket 通信。
- `index.html`: 游戏主入口。
- `style.css`: UI 样式。
