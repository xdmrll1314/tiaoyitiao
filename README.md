# H5跳一跳 (H5 Jump Jump)

这是一个基于 HTML5 和 Three.js 开发的 3D "跳一跳" 小游戏。玩家需要控制一个小方块，通过蓄力跳跃，从一个平台跳到另一个平台，挑战更高的分数。

## 🎮 游戏玩法

1. **蓄力跳跃**：长按屏幕（或按住空格键/鼠标左键）进行蓄力，蓄力时间越长跳得越远。
2. **松开起跳**：松开按键，小方块会根据蓄力大小跳向下一个平台。
3. **得分规则**：
   - 成功跳到下一个平台得 1 分。
   - **连击奖励**：如果跳到平台中心，会触发连击，分数翻倍（+2, +4, +6...）。
   - **掉落失败**：如果跳出平台范围掉落，则游戏结束。

## ✨ 特性

- **3D 视觉体验**：使用 Three.js 渲染，包含阴影、光照和正交视角，视觉效果清新简洁。
- **物理反馈**：蓄力时小方块会有压缩动画，跳跃轨迹平滑自然。
- **连击系统**：中心落点检测，连续命中中心可获得高分奖励。
- **音效系统**：包含蓄力、跳跃、落地、得分和失败的音效反馈（使用 Web Audio API 生成，无需外部素材）。
- **粒子特效**：落地时会有粒子飞溅效果，增加打击感。
- **多端适配**：支持 PC 端（鼠标/键盘）和 移动端（触摸）操作。

## 🕹️ 操作指南

| 平台 | 操作方式 |
| --- | --- |
| **PC (键盘)** | 按住 `空格键` 蓄力，松开跳跃 |
| **PC (鼠标)** | 按住 `鼠标左键` 蓄力，松开跳跃 |
| **移动端** | 按住 `屏幕` 蓄力，松开跳跃 |

## 🛠️ 技术栈

- **HTML5 & CSS3**: 页面结构与 UI 样式。
- **JavaScript (ES6+)**: 游戏逻辑实现。
- **Three.js (v128)**: 3D 场景、物体渲染与动画。

## 🚀 如何运行

1. 克隆本项目到本地：
   ```bash
   git clone https://github.com/xdmrll1314/oneDayOneProject.git
   ```

2. 进入项目目录（假设在 `2026011201` 文件夹下）：
   ```bash
   cd 2026011201
   ```

3. 启动本地服务器（推荐）：
   由于浏览器安全策略，直接打开 HTML 文件可能会导致部分功能（如音频上下文）受限，建议使用本地服务器运行。
   
   如果你安装了 Python：
   ```bash
   # Python 3
   python3 -m http.server 8080
   
   # Python 2
   python -m SimpleHTTPServer 8080
   ```
   
   或者使用 Node.js 的 `http-server`：
   ```bash
   npx http-server .
   ```

4. 在浏览器中访问：
   打开 `http://localhost:8080` 即可开始游戏。

## 📂 文件结构

- `index.html`: 游戏主入口，包含 UI 结构和库引用。

- `style.css`: 游戏 UI 样式定义。
